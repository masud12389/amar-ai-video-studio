আমার AI ভিডিও স্টুডিও — প্রাথমিক সংস্করণ

এই সংস্করণে আছে:
- বাংলা মোবাইল-ফ্রেন্ডলি ওয়েব অ্যাপ UI
- কার্টুন/বাস্তবধর্মী ধরন নির্বাচন
- ৫/১০/১৫/৩০ সেকেন্ড নির্বাচন
- 9:16, 16:9, 1:1 অনুপাত নির্বাচন
- ভিডিও তৈরির অনুরোধ JSON ফাইল হিসেবে ডাউনলোড

গুরুত্বপূর্ণ:
এটি এখনো AI ভিডিও জেনারেটর নয়। আসল ভিডিও তৈরি করতে একটি AI video generation API এবং নিরাপদ backend প্রয়োজন। API key কখনো index.html-এ রাখা যাবে না।

চালানোর সহজ উপায়:
1. ফাইলগুলো একটি ওয়েব হোস্টিংয়ে আপলোড করুন (HTTPS প্রয়োজন)।
2. index.html খুলুন।
3. Android Chrome-এর মেনু থেকে "Add to Home screen" চাপুন।
4. একই ওয়েব অ্যাপ কম্পিউটার/মোবাইল ব্রাউজারেও চলবে।

পরবর্তী ডেভেলপমেন্ট ধাপ:
- API provider নির্বাচন
- Backend endpoint তৈরি
- job status polling
- generated MP4 preview/download
- বাংলা voiceover ও subtitles
