বাংলা AI ভিডিও তৈরির ওয়ার্কস্পেস

নতুন ভিডিও তৈরি করুন

আপনার দৃশ্যের বর্ণনা লিখুন। বাস্তবধর্মী অথবা কার্টুন—দুই ধরনের ভিডিওর জন্য প্রস্তুত।

ভিডিওর প্রিভিউ

ভিডিও তৈরি হলে এখানে দেখা যাবে।
🎬

এই প্রথম সংস্করণটি অ্যাপের ইন্টারফেস। আসল ভিডিও রেন্ডার করতে পরের ধাপে একটি AI video API সংযুক্ত করতে হবে। API ছাড়া এই পেজ নিজে ভিডিও তৈরি বা আপলোড করে না।
